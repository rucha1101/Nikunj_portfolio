# Nikunj Mulkalwar Portfolio

A polished personal portfolio site for Nikunj Mulkalwar, focused on functional business analysis, ERP/CRM delivery, Agile product work, stakeholder workshops, UAT, and product ownership.

## Files

- `index.html` contains the portfolio content.
- `styles.css` contains the responsive visual design.
- `script.js` powers theme switching, project filters, expandable experience sections, email copy, and scroll reveal animations.

## View locally

Open `index.html` in a browser.

## Customize

Nikunj's LinkedIn URL is linked from the profile card. Replace the initials portrait with Nikunj's final photo when available, and add his GitHub profile/repository links if you want the project cards to link to GitHub.
